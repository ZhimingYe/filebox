浏览与预览

大目录流畅列表、面包屑、钉选；图 / PDF / 代码 / Markdown / CSV / Office 就地预览，不必先 scp 一整份。

搜索与合集

按文件名或内容正则搜索；用合集把分散路径里的文件虚拟编组，无需复制或移动。

安全默认

协议只读；敏感文件默认拒绝；可选 Transfer 与 TOTP 终端，密钥只留在 Agent。

一眼看懂架构 ​

text
浏览器 ──HTTPS──▶ Hub ◀──WSS（出站）── Agent ──▶ 本地文件
组件作用
浏览器只访问 Hub，不直连 Agent。桌面 / 手机 / 平板均可。
Hub认证用户、托管前端、把请求路由到对应机器。
Agent装在目标机上，主动出站连 Hub。目标机无需公网 IP、入站端口或 VPN。
