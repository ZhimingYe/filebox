一眼看懂架构 ​

text
浏览器 ──HTTPS──▶ Hub ◀──WSS（出站）── Agent ──▶ 本地文件
组件作用
浏览器只访问 Hub，不直连 Agent。桌面 / 手机 / 平板均可。
Hub认证用户、托管前端、把请求路由到对应机器。
Agent装在目标机上，主动出站连 Hub。目标机无需公网 IP 或入站端口。
