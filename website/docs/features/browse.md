# 浏览文件

侧栏选中 Agent 后进入 **Files**：左栏 Agent 与导航，中间虚拟滚动文件列表，右侧（桌面）多标签预览。

![Files 浏览三栏](/screenshots/01-files-browse.png)

## 界面结构

| 区域 | 内容 |
|------|------|
| 侧栏 Agents | 已连接机器、在线状态、延迟；点选切换当前 Agent |
| 侧栏 Navigation | Files / Search / Collections / Transfer / Terminal / Stats 等 |
| 地址栏 | 当前路径；支持粘贴路径与补全；刷新按钮 |
| 面包屑 | 快速回到上级 |
| 文件列表 | 名称、修改时间、大小；类型徽章；最近修改高亮 |
| 预览栏 | 点击文件即预览；桌面多标签 |

整屏布局可参考：

![侧栏总览](/screenshots/00-sidebar-overview.png)

## 常用操作

- **导航**：目录树 / 列表点进文件夹、面包屑、地址栏粘贴路径。
- **过滤**：按文件名模式、修改时间过滤。
- **类型徽章**：扩展名彩色标记；最近修改会高亮。
- **位置记忆**：刷新后回到上次目录；可 **Pin** 常用文件夹，一键跳转。
- **下载**：预览栏提供 Download；浏览本身不改远端文件。
- **手机**：小于 768px 用抽屉侧栏；列表与预览全屏切换。

## 和演示的差异

演示里 Files 可点进 mock 目录树并预览流式加载条。真实应用还会：

- 连真实 Agent 根目录（需先 [Add Root](/guide/first-login)）；
- 多标签预览与键盘快捷键；
- 超大文件加载前确认，避免拖死浏览器。
