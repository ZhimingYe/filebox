Agents reach out. The firewall stays shut.

Every other remote-access tool asks you to open a hole toward the machine. Filebox inverts the direction: the agent opens one long-lived outbound WebSocket. Your browser only ever talks to the hub.

Browser → Hub

Standard HTTPS

One URL for the web app. Auth, browsing, search, and previews all go through the hub you control.

Agent → Hub

Outbound WSS only

Agents dial home from lab HPC, laptops, or edge boxes. No public IP and no inbound port on the agent side.

Firewall

Untouched

No VPN, no port mapping. When a machine returns, the agent reconnects with a stable identity.

See the figure. Not the path to it.

Plots, matrices, tables, PDFs, Markdown, code, HTML, and optional Office conversion — rendered where the file lives, the moment you click.

Made for people who live in data.

Researchers and analysts with files on shared servers — preview the figure, read the dataset, check the box, move on. Browsing stays read-only; write paths are deliberate and narrow.

The death of scp

Stop copying a heavy file to your laptop just to glance at one plot. The figure renders on the server, through the browser.

Safe by default

Browsing cannot modify or delete files. Credentials and secrets are denied by default. The two intentional exceptions are the per-agent temp transfer folder and an optional TOTP-guarded terminal (unsandboxed).

5 min self-hosted

From download to browsing quickly.

Pre-built static musl binaries. No Rust toolchain, no Node, no Docker. A binary and --init-config.

1
Grab the release tarball
Hub on your exposed machine, agent on each backend.
2
Init hub config
./bin/hub --init-config — creates config/hub.json and prints the agent token once.
3
Run the hub
./bin/hub — serves the UI on :3000.
4
Init & start agents
./agent --init-config then ./agent — dials out to the hub. Add roots from the UI.
zsh — hub
$ tar xzf filebox-hub-*-x86_64-musl.tar.gz
$ cd filebox-hub-*
$ ./bin/hub --init-config
# → listen address, admin credentials, agent token (printed once)

$ ./bin/hub
  filebox-hub v2.1.0

$ ./agent --init-config
